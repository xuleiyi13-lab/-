# Deconstructed Duotone Poster

A Codex skill for turning a supplied image or text-only theme into a spacious editorial duotone print with exact square-panel layouts, pale ivory paper, one chosen ink color, restrained print texture, and a quiet two-line footer.

## Included

- Portrait 3:4 nine-square and vertical four-panel layouts
- Landscape 4:3 six-square and horizontal four-panel layouts
- Complete `SKILL.md`, agent metadata, layout guides, and reference rules
- MIT license preserved from the original project

## Install in Codex

```bash
git clone https://github.com/xuleiyi13-lab/-.git deconstructed-duotone-poster-repo
mkdir -p ~/.codex/skills
cp -R deconstructed-duotone-poster-repo/deconstructed-duotone-poster ~/.codex/skills/deconstructed-duotone-poster
```

The skill becomes available on the next Codex turn.

Example:

```text
用 $deconstructed-duotone-poster 做一张关于公路、沙滩和大海的砖红色海报。
```
